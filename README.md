## 📌 Описание

**Hardware Spoofer** — это утилита, разработанная для продвинутой подмены железных компонентов системы. Она позволяет изменять серийные номера и идентификаторы, которые операционная система передает программам, играм и античитам.

Инструмент работает на низком уровне, обеспечивая максимальную эффективность и скрытность.

### 🔥 Возможности
- 🖥️ **Спуфинг материнской платы** (Serial Number, UUID).
- 💾 **Подмена HDD/SSD** (Serial Number, Model Name).

## ⚙️ Установка и использование

### Требования
- Windows 8/10/11 (x64).
- Права администратора.


### Быстрый старт
1. **Скачайте** последний `Spoofer.exe` из [Releases](https://github.com/Onyokot/Spoofer/releases).
2. Запустите файл **от имени администратора** (ПКМ → Запуск от имени администратора).
3. В главном меню выберите необходимые компоненты для подмены.
4. Нажмите кнопку **"Сменить серийник"**.
5. Дождитесь завершения процесса и перезагрузите компьютер.

> 🚨 **Важно:** Перед запуском закройте все игры и приложения, использующие античит-системы (например, Vanguard, EAC, BattlEye).
