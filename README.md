# Spoofer
Инструмент для подмены аппаратных идентификаторов и характеристик устройства в играх. Предназначен для тестирования, исследований и изучения механизмов аппаратной идентификации и античит-систем в контролируемой среде. Позволяет исследовать, как изменение параметров оборудования влияет на распознавание устройства и работу игровых систем.
